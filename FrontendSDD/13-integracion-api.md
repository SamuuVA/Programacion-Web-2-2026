# 13 — Integración API
OpenAPI aprobado es fuente del contrato. Crear HttpApiAdapter, DemoDataAdapter, DTOs, mappers y normalización ApiError. No inventar endpoints. No llamar fetch disperso desde componentes. No reintentar automáticamente operaciones no idempotentes. Resultado desconocido de pago no equivale a fallo. Modo demo separado, explícito y nunca confundido con producción.
