# NexusMarket Frontend SDD
Base documental para comenzar la implementación universitaria del frontend.

Stack: Next.js App Router, React y TypeScript. Objetivo: entregar primero un sitio navegable y medianamente funcional, y perfeccionarlo por iteraciones.

Orden: leer 00, 01, 02 y 20; ejecutar OLA 0; construir fundación; sitio público/catálogo; Buyer; Seller; Administrator; módulos operativos según contratos.

`legacy/` conserva los documentos frontend anteriores si estaban incluidos en el ZIP fuente. Los documentos de raíz son la guía consolidada de implementación.

No inventar endpoints, campos, permisos, stock, precios, métricas ni estados. Si el backend no está disponible, usar datos demo claramente rotulados y separados del adaptador HTTP real.
