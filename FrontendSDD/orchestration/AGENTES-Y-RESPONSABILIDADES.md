# Agentes y responsabilidades
- Architect: estructura, layouts y configuración.
- Design System: tokens y componentes base.
- Public Catalog: home, catálogo y detalle.
- Buyer: carrito, checkout y pedidos.
- Seller: productos y portal.
- Administrator: vendedores y bodegas.
- Logistics: tareas logísticas contratadas.
- Supervisor: consultas contratadas.
- API Integration: cliente HTTP, DTOs y adaptadores.
- Security: sesión, rutas y privacidad.
- QA: pruebas, responsive y accesibilidad.
- Reviewer: auditoría independiente.

Cada agente reporta archivos, fuentes, pruebas reales, limitaciones, riesgos y READY_FOR_REVIEW o BLOCKED. No puede aprobar su propio trabajo.
